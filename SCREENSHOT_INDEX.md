# Screenshot index and provenance

All images are authentic captures of the supplied **M51R1** normal ROM, obtained using the **NGPCraft Studio 4.3.2** emulator core and BIOS in the development package. Native output is **160 × 152 RGBA**; image files are **4× nearest-neighbour scaled PNGs**. This does not imply a complete physical-hardware playthrough. No synthetic or AI-generated gameplay frames are included.

| Images | Content | Capture route |
|---|---|---|
| `01`–`03` | Title and opening scenes | Normal ROM, emulator |
| `04` | Classic stage 1 | Normal game start |
| `05`–`10` | Classic stages 2–7 | Hidden stage-select debug path (scores locked) |
| `11` | SNK stage 1 | Direct SNK sprite development preview (scores locked) |
| `12`–`14` | SNK stages 3, 5, 7 | Hidden stage-select + SNK sprite cheat (scores locked) |
| `15`–`17` | Options, lives/continues, cheat menu | Normal ROM UI navigation |
| `18`–`20` | Terry/Evil Ryu arena and K.O. | M51R1 native fight regression screenshots |
| `21`–`33` | Ending dialogue, gift scene, homecoming, credits | M51R1 native ending fixture, story-SNK branch |

The original test script uses historical `M50_` labels for some captures, but was run against the **M51R1** game and maps. Screenshots were selected by inspecting the rendered frames. No ROM, BIOS, third-party sprite sheets or tool binaries are distributed alongside this GitHub showcase.
